# Earth Day Platform

A premium, editorial landing page concept for a sustainability recognition platform.

## Design direction

- Deep forest green, dark moss, warm cream, and sage.
- Oversized sans-serif display type paired with italic serif accents.
- Editorial forest photography, generous spacing, thin rules, and responsive content bands.
- Responsive mobile navigation and anchor-based section navigation.

## Run locally

```bash
npm install
npm run dev
```

## Concept status

This repository contains a design concept, not an operating certification program. Partner wordmarks, recognition criteria, application stages, and contact details are illustrative. They must be replaced or verified before the site is presented as an active service. No environmental certification, endorsement, or performance claim is implied.

## Stack

Next.js 14, React 18, TypeScript, Tailwind CSS.
