# Earth Day Platform

A portfolio website concept exploring a sustainability recognition framework.

## Art direction

Earth Day is designed as an evidence-led field note and standards journal, rather than a nature-photography-led environmental brand. The visual language uses warm mineral paper, ink-like charcoal, one signal-orange accent, and a chartreuse cover sheet. A custom geometric mark and an illustrative standards sheet create a graphic identity without implying a real certification.

The page uses editorial hierarchy, asymmetric content layouts, numbered index rows, clear rules, and a process-led narrative. It intentionally avoids stock forest imagery, fabricated partner logos, unverified impact statistics, and generic feature-card grids.

## Project status

This is a portfolio concept only. It is not an operating certification service. The mark, principles, process, and review stages are illustrative. No certification, endorsement, partner relationship, or environmental performance claim is implied.

## Run locally

```bash
npm install
npm run dev
```
